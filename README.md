# شصت جلسه تا روانی — Speaking 60

یک برنامهٔ ۶۰ جلسه‌ای و قدم‌به‌قدم برای تقویت Speaking انگلیسی (محیط کار و مکالمهٔ روزمره)، برای سطح Intermediate تا Upper-Intermediate.

- جلسهٔ صفر: ارزیابی اولیه (تحلیل ضبط‌ها + آزمون شفاهی شبیه IELTS با ChatGPT Voice + خودارزیابی)
- ۶ فاز × ۱۰ جلسه؛ جلسه‌های ۱۰، ۲۰، … ۶۰ مرور و ارزیابی با همان آزمون‌های ثابت
- هر جلسه: مرور فاصله‌دار خودکار (۱/۳/۷/۱۴/۲۸ جلسه قبل)، لغت، Phrasal Verb، عبارت، گرامر گفتاری، Shadowing با لینک TED/BBC، تلفظ با YouGlish، تمرین روانی، پرامپت آمادهٔ ChatGPT Voice، چالش ضبط‌شده
- دفتر خطا، لیست سخت‌ها و ثبت عددی پیشرفت (ذخیره در localStorage مرورگر، با پشتیبان‌گیری متنی)

## اجرا

فایل `index.html` را مستقیم در مرورگر باز کنید. بدون نیاز به سرور یا build؛ فقط فونت‌ها از Google Fonts بارگذاری می‌شوند.
